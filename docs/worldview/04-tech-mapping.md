## 2. 不浪费：现有能力怎么复用

| 现有实现 | 在《鸣沙》里变成 |
| --- | --- |
| `WorldTerrain` 8×8 chunk、顶点色 | 沙海与岩脊，只换色板与材质 |
| 水面单四边形 | 卤湖（改材质、调浮力） |
| `ThirdPersonController` 游泳 | 卤湖游泳（浮力目标深度调浅） |
| `WorldSyncClient` 10 Hz 快照 | 玩家位置同步（不变） |
| `RoomClient` 20 Hz 整数帧同步 + 近战 | 渊盐点争夺（规则不变，只换皮） |
| `ArenaClient`（Quake III） | 井塔内部"试炼场"（可选，不作为主线） |
| RUDP | 大潮/长者事件广播、房间消息 |
| 预测 + 回滚 | 帆撬高速移动（误差更明显，正好演示） |
| `CaptureDemoShot` 固定机位 | 双端对照帧（沿用同一套相机参数） |
| PlayMode 测试 | 新增沙地物理、事件触发测试 |

**没有一项现有功能被丢弃**。这是选择"沙漠行星"而不是"重做一套世界"的原因。

## 4. Unity 落地路线

### M1 · 主题与光（1–2 天）

| 任务 | 改动 |
| --- | --- |
| 世界变体 | `worldgen` 加 `-theme` 参数；生成 `world/themes/ashkar/`；`generate-world.cmd` 加 `-Theme`（**此时只复制到 Unity，不写 UE 目录**）；Unity `WorldData` 支持 `AI003_WORLD_VARIANT=ashkar`，从 `StreamingAssets/world-ashkar/` 读 |
| 天空 | 程序化天空 Shader：双日圆盘、尘天渐变、夜间星空 |
| 光照 | 主光 + 伴光（第二盏方向光，仅主相机可见的距离内投影） |
| 雾 | URP 线性雾 + `FullScreenPassRendererFeature` 高度雾 |
| 后处理 | Volume Profile：ACES、Bloom、Vignette、Grain、CA、Split Toning、Letterbox |
| 地形材质 | `AI003/TerrainVertexColor` 扩展：三平面沙纹法线、wrap diffuse、向上面积尘 |

**验收**：`RenderWorldPreview` 出新图；与 `docs/images/worldview/ashkar-basin.png` 的色相一致；
`smoke-unity` 通过；`demo-compare` **仍然用旧世界**（不破坏双端基线）。

### M2 · 地标与道具（2–3 天）

| 任务 | 内容 |
| --- | --- |
| 井塔 | 倒锥塔身 + 顶部平台 + 深窗；编辑器脚本程序化生成 |
| 第一井 | 下沉圆形广场 + 螺旋坡道 + 钟架 |
| 骨拱 | 3–5 处天然拱，替换骨脊上的若干位置 |
| 帆撬 | 三滑板 + 帆 + 货斗；可驾驶 |
| 井民 NPC | 3–5 个静态/巡逻角色（复用 Kenney 资产先占位） |

**验收**：S1 截图；场景内 draw call 增量 < 150；无编译错误。

### M3 · 事件与物理（3–5 天）

| 任务 | 内容 |
| --- | --- |
| 帆撬物理 | 各向异性摩擦、侧倾、风帆推力、沙面射线平滑 |
| 长者过境 | Spline 路径 + 沙面顶点位移 + 冲击波 + 相机震动 + 低频音 |
| 大潮 | 视觉墙（层叠网格 + 噪声）+ 全屏色偏 + 能见度衰减 |
| 冷火 | 晶簇自发光 + 夜间 Bloom + 采集破碎粒子 |

**验收**：PlayMode 测试（沙面位移、刚体抛起、帆撬不穿地）；S3/S4 截图；帧率 ≥ 60。

### M4 · 网络化（3–5 天，含服务器）

| 任务 | 内容 |
| --- | --- |
| `world.tide` | 服务器按 tick 计算墙位置；10 Hz 广播；客户端插值 |
| `world.elder` | 服务器调度事件（起点/方向/时刻）；客户端本地表现 |
| `world.node` | 渊盐点表 + 占用状态；进房下发，变化广播 |
| 协议 | 新增字段，**向后兼容**：Go 的 `encoding/json` 默认忽略未知字段；UE 侧需确认其解析器同样忽略，否则先在服务端按客户端能力裁剪 |

**验收**：`demo-room` 双端一致；`/demo` 计数正常；新增 Go 单测；S5/S6 截图；
**UE 端不修改**，仅验证它仍能连上、仍能跑（向后兼容）。

## 6. 风险与取舍

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| URP 17.6 无内置体积雾 | 尘雾效果受限 | 全屏高度雾 Pass + 光柱粒子；不做真体积 |
| 第二盏方向光阴影成本 | 中低端掉帧 | 阴影距离 120 m；远景用烘焙 AO 代替 |
| 顶点色地形缺细节 | 近景发"糊" | 三平面法线 + detail map + 顶点色对比增强 |
| 长者体型过大 | 骨骼动画不现实 | 分段网格 + 顶点位移 + Shader 弯曲，不做骨骼 |
| 帆撬高速抖动 | 预测误差大 | 射线平滑法线 + 固定步长物理 |
| 世界数据改动影响 UE | 双端不一致 | 新主题放独立目录 `world/themes/`，`world/` 不动 |
| `demo-compare` 基线失效 | CI 红 | Phase 2 期间对照仍用旧主题；Phase 3 再切 |
