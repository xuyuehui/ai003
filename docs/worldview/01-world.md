# 01 · 世界：阿什卡与白喉盆地

> 本章定义"场景里到底有什么"。所有数值都以**米、秒、Y 轴向上**为单位，与 `world/world.json` 一致。

## 1. 天体

| 项 | 值 | 对演示的意义 |
| --- | --- | --- |
| 星球 | **阿什卡（Ashkar）**，旱海型 | 单一主场景，不需要多星球 |
| 星图编号 | **ASH-7**（官方档案口径） | 给 UI / 档案文本一个"制度感"的来源 |
| 表面重力 | 1.2 g | 只用于叙事；角色手感仍按 `ThirdPersonController` 调参 |
| 自转 | 40 小时／环（cycle） | 昼夜可以做得慢，一场 10 分钟的演示只经历一个光段 |
| 大气 | 稀薄、富尘、低湿度 | 远景色偏灰白、太阳低角度时强散射 |
| 双日 | **赫斯（Hes）** 白炽主星 + **维尔（Vyr）** 暗红伴星 | **双影**：两个方向、两种色温的投影 |
| 双月 | 砂月、盐月（无正式名，井民按盈亏称"薄/厚"） | 夜景主光 + 冷火发光的对照 |

**双影是这套设定最便宜、最有效的视觉签名**：同一场景里两个方向不同、软硬不同的影子，
一眼就能和"普通沙漠场景"区分开，而且实现成本只是第二盏方向光 + 一次阴影。

> 注意：真实双星系统的光照会随公转剧烈变化。演示里把维尔当作"固定在天空一角的暗红补光"，
> 不做轨道模拟 —— 这是刻意的取舍，写在这里避免以后有人来"修正"它。

## 2. 时间

- 一环 = 40 小时，分四段：**白昼（Day）→ 暮尘（Dust Dusk）→ 霜夜（Frost Night）→ 晨雾（Dawn Haze）**。
- 演示里一环压缩到 **8 分钟**（每段 2 分钟），保证一次演示能看到完整的光段变化。
- **大潮**不是日循环的一部分，它是独立周期事件（见 §8），叠在任意光段上。

## 3. 地理：白喉盆地

演示区域是一块 **2048 m × 2048 m** 的采样区，不是整颗星球。地形数据、出生点、尺寸全部来自
`world/world.json`（seed `20261103`，513×513 顶点，4 m/格，盐海基准面 0 m，最高 396 m，最低 −76 m）。

### 3.1 分区

| 分区 | 位置 | 形态 | 叙事作用 |
| --- | --- | --- | --- |
| **白喉盐海** | 环绕盆地外缘，基准面 0 m | 干盐湖，盐壳龟裂成板块，反光极强 | 地平线的"白"，让远景有层次 |
| **盐壳滩** | 0–9 m | 盐与沙的过渡，薄壳下是湿泥 | 行走时"咔"的碎壳音与碎屑粒子 |
| **砾漠** | 9–150 m，缓坡 | 风蚀砾石平原，有定向风纹 | 大面积中景，做风蚀条纹与热浪 |
| **长眠海** | 盆地东侧与南侧，9–150 m | 沙丘场，波长 40–120 m | 主舞台：沙纹、足迹、沙崩 |
| **骨脊** | 中央与西北，> 150 m 或坡度 > 30° | 柱状节理玄武岩，峡谷、天然拱 | 遮挡、峡谷战斗、可破坏岩体 |
| **霜冠** | 两处山峰 > 300 m | 盐霜与冰，表面接近纯白 | 画面里的"过曝点"与尺度参照 |

### 3.2 两处卤湖

盆地内部有两个低洼卤湖（数据里就是低于 0 m 的水体区域，渲染上用高密度卤水材质）：

- **东眼**：最大的一处，镜面反射天空，是"双日倒影"镜头的最佳机位。
- **南眼**：较小，边缘有盐柱。

卤水密度大（1.3 t/m³），角色浮得比淡水高 —— 现有游泳逻辑**不需要改**，只是把浮力目标深度调浅。

### 3.3 地标

| 地标 | 位置 | 用途 |
| --- | --- | --- |
| **第一井（Well One）** | 出生点 `(168, 39.7, −8)` | 井民竖井聚落；所有演示的起点与"安全区" |
| **骨拱（Bone Arches）** | 骨脊峡谷内，3–5 处 | 前代文明遗迹，做尺度对比与大结构 AO |
| **旧盐道（Old Salt Road）** | 从第一井向东北的硬地车辙 | 帆撬的天然赛道，物理演示的固定线路 |

> 骨拱不是"上古高科技"，就是**被风蚀穿的天然岩拱 + 少量人工加固痕迹**。
> 避免引入"失落的先进文明"这种会膨胀成剧情的设定。

## 4. 生物群系映射（Phase 2 的最小改动路径）

现有世界已经烘焙了 6 个 biome id。**不改 id、不改生成器结构**，只换语义与色板：

| id | 现在 | 阿什卡语义 | 材质要点 | 兑换的技术点 |
| --- | --- | --- | --- | --- |
| 0 | 海洋 | **白喉盐海** | 盐壳 + 卤水，高粗糙度、强镜面 | SSR、远景雾、平面反射 |
| 1 | 沙滩 | **盐壳滩** | 盐晶，细碎高光 | 细节法线、碎屑粒子 |
| 2 | 草地 | **砾漠** | 砾石 + 风蚀条纹，无植被 | 大面积中景着色、风向各向异性 |
| 3 | 沙漠 | **长眠海** | 沙，沙纹法线、风移、足迹 | 地形细分、位移、拖尾 |
| 4 | 岩石 | **骨脊** | 柱状节理玄武岩，暗、硬 | 三平面映射、AO、可破坏 |
| 5 | 雪 | **霜冠** | 盐霜/冰，接近纯白 | 高光溢出、Bloom 控制 |

**关键决定：草地（占 34%）变成砾漠，而不是绿洲。**
一颗沙漠行星不该有三分之一的绿地；绿洲只作为"第一井"周边几十米的人工灌溉斑块存在，
这样既有生命色，又不会破坏整体色调。

色值见 [03-art-direction.md](03-art-direction.md) 与 `docs/images/worldview/palette.png`。

## 5. 水

阿什卡没有开放水体。全部的水以三种形式出现：

1. **卤湖**：地表可见，高盐、镜面、不可饮用 —— 视觉与物理道具。
2. **井水**：井民的竖井打到地下含水层，是第一井聚落存在的原因。
3. **大气水**：夜间凝结在盐壳与织物上的薄霜，晨雾段融化 —— 只做视觉。

**不做**：水体模拟、流体、蒸发循环。卤湖就是一个平面 + 材质。

## 6. 渊盐 / 冷火

| 项 | 内容 |
| --- | --- |
| 形成 | 前代海洋蒸发后，盐层被沙掩埋、被地压重结晶 |
| 外观 | 半透明青白色晶簇，从沙里"长出"，成脊状排列 |
| 夜间 | 吸收的白日热量以冷光释放 → **青白色自发光**，俗称冷火 |
| 白日 | 接近透明，只在沙面上留下一点点偏青的色偏 —— 需要走近才看得见 |
| 采集 | 敲击/切割晶簇，会向沙层传导**低频振动** |
| 分布 | 沙海下 0.5–3 m，沙丘迁移后暴露；由世界生成器按噪声 + 沙丘脊线布点 |

设计意图：

- **夜间的青白自发光** 与暖沙形成唯一的高饱和对比，是做 Bloom / 自发光 / 色彩分级的最佳载体。
- **采集即振动** 把"资源点"和"巨兽事件"绑在一条因果链上 —— 不需要写任务系统，玩家自己会发现。
- 结晶的**折射**可以做色散高光（双日穿过晶体在沙面投出彩色光斑），这是纯渲染展示。

## 7. 鸣沙兽（长者 / The Elder）

| 项 | 内容 |
| --- | --- |
| 体型 | 成年 180–400 m 长，体高 30–50 m |
| 解剖 | 环节甲壳；**三瓣颚**（像花一样张开，不是圆口利齿）；背脊一列**晶簇**；体侧有螺旋排列的鳞板 |
| 运动 | **螺旋潜行**：在沙下沿螺旋线推进，沙面留下连续的环形隆起与尾迹 |
| 感知 | 对 20–80 Hz 的低频振动敏感；不靠视觉 |
| 行为 | 不主动捕食。被强振动扰动时**穿越**该区域，沿途抬升沙层、掀翻建筑、把角色抛起 |
| 生态位 | 沙层翻动者：它把深层的渊盐翻到地表，所以"有冷火的地方，长者来过" |
| 声音 | 低频鸣响（20–40 Hz），沙面共振时像远处的钟 —— 这就是"鸣沙"的名字来源 |

**与《沙丘》沙虫的差异（重要）**：三瓣颚而非圆口利齿、背脊晶簇而非环节裸露、螺旋横向潜行而非垂直冲出、
非捕食性的"翻沙者"而非吞噬一切的怪物。见 [05-legal.md](05-legal.md)。

**演示用法**：不做一个 AI 敌人，只做一个**路径动画 + 地形/刚体扰动**的"环境事件"。
它不追人、不攻击、不死亡，只是经过 —— 这样既省掉战斗 AI，又能把物理与网络同步拉满。

## 8. 大潮（The Tide）

| 项 | 内容 |
| --- | --- |
| 形态 | 一堵高 200–400 m 的沙暴墙，从盆地西侧推进到东侧 |
| 周期 | 演示里 **每 4 分钟**一次（世界内设定为"每 3 环一次"） |
| 速度 | 约 12 m/s，横穿 2048 m 约 170 秒（墙过境时是持续的压迫感，不是一闪而过） |
| 影响 | 能见度降到 30 m；沙面摩擦上升；飞行/滑行载具速度下降；渊盐采集中断 |
| 权威 | **墙的位置只由服务器计算**，客户端只做表现与插值 |

这是"网络同步"最直观的展示：所有人抬头看到的是同一堵墙、同一个位置、同一个到达倒计时。
比同步一百个玩家位置更容易被一眼看懂。

## 9. 昼夜与光

| 光段 | 主光 | 色温 | 视觉要点 |
| --- | --- | --- | --- |
| 白昼 | 赫斯高角度 | 5600 K | 短硬阴影、沙面高光、天空灰白 |
| 暮尘 | 赫斯低角度 + 扬尘 | 3200 K | 长阴影、橙红散射、体积光柱 |
| 霜夜 | 双月 + 冷火 | 9000 K | 深蓝紫、冷火青白自发光、星空 |
| 晨雾 | 赫斯初升 | 4800 K | 低对比、贴地雾、盐壳反光 |

**双影**在暮尘段最明显：赫斯投出暖色长影，维尔投出暗红短影。

## 10. 生态（三层，够用就好）

1. **生产者**：盐壳上的嗜盐菌膜（晨雾段泛一点点绿，是画面里唯一的"生物绿"）。
2. **消费者**：小型沙蟹（贴地爬行的小物件，做地面细节与脚步交互）。
3. **扰动者**：鸣沙兽。

**不做**：食物链模拟、种群、AI 生态。前两层只是"会动的小道具"。

## 11. 世界生成需要改什么（Phase 2 之后）

现有生成器的**结构不动**，只加主题层：

| 改动 | 说明 |
| --- | --- |
| `worldgen -theme ashkar` | 输出到 `world/themes/ashkar/`，`world/` 保持原样（UE 不受影响） |
| 调色板 | `surfaceColor()` 换成 §4 的色值，逻辑分支不变 |
| 沙丘场 | 在 desert 区域叠加**定向沙丘**（波长 40–120 m 的正弦脊 + 噪声扰动），提高中景可读性 |
| 渊盐点位 | 生成 `venasalt.json`：N 个点（x,z,暴露度），供服务器与客户端共用 |
| 出生点规则 | 不变（仍是"海平面以上、坡度 < 15°、半径 30 m 干燥"） |

**不做**：动态地形、可挖掘地形、沙的 SPH 模拟。沙面位移只做**视觉**，碰撞体保持静态高度场。

## 12. 明确不做的事

- 不做剧情、对话、任务、过场。
- 不做多种族/多星球/星际旅行。
- 不做天气系统，只有"大潮"这一个事件。
- 不做水体模拟与生态模拟。
- 不做"上古高科技文明"（骨拱只是天然岩拱 + 人工加固痕迹）。

任何一条被打破，都要先在 [04-tech-mapping.md](04-tech-mapping.md) 里证明它兑换了什么技术点。
