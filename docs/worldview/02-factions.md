# 02 · 势力、建筑与器物

> 本章定义"东西长什么样、属于谁"。三股势力只提供**视觉与归属**，不提供玩法系统。

## 1. 三方关系

```
                 ┌──────────────────────────┐
                 │  曜庭 The Solar Court    │  特许开采方：要配额、要秩序
                 │  骨白 / 黄铜 / 对称      │
                 └───────────┬──────────────┘
                             │  争：渊盐归谁
                 ┌───────────┴──────────────┐
                 │  盐路盟 The Salt Road    │  运输行会：要路权、要自由
                 │  赤褐 / 炭黑 / 非对称    │
                 └───────────┬──────────────┘
                             │  都依赖
                 ┌───────────┴──────────────┐
                 │  井民 The Wellfolk       │  中立：卖水、守井、不参战
                 │  盐白 / 绳结 / 下沉      │
                 └──────────────────────────┘
```

**冲突只有一句话**：曜庭拿到了盆地的开采特许，盐路盟认为盐道和盐都不该被一家垄断。
没有王位、没有血仇、没有宗教战争 —— 因为技术演示不需要它们。

## 2. 曜庭（The Solar Court）

| 项 | 内容 |
| --- | --- |
| 性质 | 星际特许经营机构。"曜庭"原本是董事会所在地的名字，后来被用来指代整个机构 |
| 目标 | 完成渊盐配额，维持特许权，把盆地变成一张可审计的报表 |
| 组织 | 监察官（Warden）→ 工程队 → 合同守卫；全部以编号称呼，不用姓名 |
| 在盆地 | 三座 **井塔**（Wellspire），一座移动井架，若干界桩 |
| 台词调性 | 公文、编号、配额、天气通告。不说比喻句 |

## 3. 盐路盟（The Salt Road Compact）

| 项 | 内容 |
| --- | --- |
| 性质 | 本地运输行会。起源是把盐从盐海驮到绿洲的驮队，后来学会用废弃船体拼装沙橇 |
| 目标 | 保住盐道的通行权，让渊盐"流动"而不是被囤积 |
| 组织 | 没有层级，只有"车队"。谁的车在前面谁说了算 |
| 在盆地 | 移动营地（3–4 辆帆撬围成圈）、盐道上的补给桩 |
| 台词调性 | 行话、押韵的计数、给每段路起外号 |

## 4. 井民（The Wellfolk）

| 项 | 内容 |
| --- | --- |
| 性质 | 定居的守井者。不是游牧民族，不是反抗军，**不参战** |
| 生计 | 打井、卖水、维护盐道上的水点 |
| 社会 | 井是公共财产；水以**绳结**计量（一结 = 一日的成人饮水）；以钟声报时 |
| 聚落 | **第一井**：竖井 + 螺旋坡道 + 下沉圆形广场，盐砖砌成，半埋在地下 |
| 台词调性 | 短句、谚语、只谈水与天气 |

井民是**唯一有"生活感"的势力**：晾晒的织物、蓄水的陶罐、钟、孩子。
他们存在的目的是让盆地不像一个纯竞技场 —— 这对渲染演示（生活细节、布料、小道具）有用。

## 5. 为什么是"公司 + 行会"，不是"贵族家族 + 皇帝"

这是本设定与《沙丘》**最重要的结构性差异**，也是简化：

- 《沙丘》的戏剧引擎是**封建继承 + 皇权 + 预言**；我们一个都不要。
- 公司 vs 行会的冲突是**合同与路权**，天然适配"服务器权威 + 规则同步"的技术叙事：
  配额、界桩、通行许可都可以是服务器上的状态，而不是剧情。
- 少了皇帝、贵族、修会、宇航公会，就少了四套需要设计的视觉体系 —— 对演示是减负。

**不做**：王室、封号、家族纹章、预言、救世主、宗教修会、刺客组织。

## 6. 建筑语言：沙漏母题

整套人造物的形式母题只有一个：**漏斗 / 倒锥 / 沙漏**。

| 部位 | 形态 |
| --- | --- |
| 井塔 | 倒锥形塔身，顶部是平台，底部收进沙里；远看像一枚插在沙里的沙漏 |
| 门洞 | 漏斗形内凹，越往里越窄 |
| 头盔面罩 | 倒锥形，下缘收窄 |
| 载具货斗 | 漏斗形，卸货靠重力 |
| UI 刻度 | 沙漏的两段式刻度 |

**为什么统一**：沙、水、光、时间在阿什卡都以"从上往下漏"的方式存在。
一个母题就能把建筑、器物、界面串起来，而且和《沙丘》的**金字塔/巨碑**语言明显不同。

### 6.1 曜庭建筑

- 材料：喷射混凝土（粗、有模板痕）+ 骨白陶瓷板 + 黄铜接头。
- 特征：**对称**、**厚墙**、**深窗**（窗洞进深 ≥ 1.5 m，形成强明暗对比）。
- 尺度：井塔 80–150 m，是画面里的"巨构参照"。
- 内部：单一光源（顶部漏斗天窗），其余全暗。

### 6.2 盐路盟建筑

- 材料：回收船体蒙皮 + 炭黑桁架 + 赤褐帆布 + 绳。
- 特征：**非对称**、**缝合**、**可拆卸**；能看到螺栓、补丁、绳结。
- 尺度：20–40 m，永远比人高一点，但不构成"巨构"。
- 与曜庭的对比：一个像纪念碑，一个像行李。

### 6.3 井民建筑

- 材料：盐砖（半透明、会反光）+ 绳 + 织物。
- 特征：**下沉**、**圆形**、**螺旋**。地面之上只有矮墙和钟架。
- 尺度：直径 30–60 m 的下沉广场，深 15–25 m。

## 7. 载具：帆撬（Sail-sled）

| 项 | 内容 |
| --- | --- |
| 形态 | 三条沙橇滑板 + 可收放的三角帆 + 后部货斗；无轮 |
| 动力 | 风（大潮前风力最强，速度最快 —— 危险与收益同源） |
| 驾驶 | 一人操帆，一人配平；配平靠身体重心移动 |
| 视觉 | 帆是赤褐/骨白的拼接布，破口用绳缝；滑板下永远拖着两道沙痕 |
| 物理 | 三滑板与沙面的**各向异性摩擦**（顺沙纹方向阻力小）；转向靠侧倾 |

帆撬是**物理演示的主角**：它同时用到摩擦力各向异性、悬挂/侧倾、风力、沙面接触，
而且它的速度足够高，能把网络同步的预测/回滚压出问题来 —— 这正是我们想要展示的。

**不做**：飞行器、扑翼机、悬浮车。地面载具一个就够。

## 8. 服装：三层结构

| 层 | 作用 | 视觉 |
| --- | --- | --- |
| 内衬 | 吸汗、隔热 | 贴身、深色、几乎看不见 |
| 滤尘层 | 挡沙 | 大量褶皱、可拆、领口与袖口收紧 |
| 外披 | 反光、伪装 | 沙色/骨白，宽大，走动时扬起 |

三股势力的差别只在**外披**：

- 曜庭：硬质陶瓷片外披，像鳞甲，边缘整齐。
- 盐路盟：拼接帆布，补丁、绳结、褪色。
- 井民：盐壳处理过的厚布，泛白，下摆拖地。

**刻意不做**：全身管路、循环系统、面罩导管。
"把人体包进一套机械"是《沙丘》蒸馏服的标志性表达，我们改用"层叠织物 + 陶瓷片"，
靠**褶皱与硬片的反差**建立识别度（见 [05-legal.md](05-legal.md)）。

## 10. 命名法

避免"阿拉伯语借词堆砌"—— 那是《沙丘》的声音。我们用自己的构词规则：

| 类别 | 规则 | 例 |
| --- | --- | --- |
| 地名 | **汉语描述性复合词**，直接说它像什么 | 白喉、骨脊、长眠海、霜冠 |
| 英文转写 | 意译，不音译 | White Throat / The Spine / The Long Sleep |
| 机构 | 汉语双字 + 机构类型 | 曜庭、盐路盟 |
| 人名 | 职称 + 编号（曜庭）/ 绰号（盐路盟）/ 井名 + 排行（井民） | Warden 3-7 / 老辙 / 第一井·三女 |
| 器物 | 功能 + 形态 | 帆撬、井塔、骨拱 |

**禁用**：任何听起来像阿拉伯语/波斯语专有名词的堆砌（`Ar-`、`-ul-`、`Shai-`、`Bene-` 之类），
以及任何与《沙丘》专有名词同形或近形的词。清单见 [05-legal.md](05-legal.md)。

## 11. 社会细节（只做氛围，不做系统）

- **水**是硬通货；井民以绳结计水；曜庭以配给券计水；盐路盟以"一趟"计水。
- **时间**：井民敲钟报时，曜庭用标准时（编号），盐路盟不看表只看风。
- **葬俗**：沙葬 —— 把遗体交给长眠海。所以沙路盟忌讳在沙丘上大声说话。
- **禁忌**：不在夜里点火（会引来长者）；不在盐海上跑（壳会碎）。

这些细节只用三种方式出现：**环境道具、HUD 文案、NPC 的一句台词**。
不写对话树、不写任务。

## 12. 明确不做的事

- 不做阵营选择、声望、任务、商店。
- 不做角色自定义、装备、技能。
- 不做 NPC 行为树（井民只是站着、走着、敲钟）。
- 不做剧情演出与过场动画。
