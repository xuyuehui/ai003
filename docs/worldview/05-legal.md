# 05 · 法律风险与规避

> **本文不是法律意见。** 它是一份给制作团队用的"红线清单 + 差异化记录"，
> 用来保证我们的设计是独立创作，而不是对《沙丘》的复制或改写。
> 正式发行前必须由 IP 律师做一次 FTO（freedom-to-operate）审查。

## 1. 结论先行

| 问题 | 结论 |
| --- | --- |
| 做"沙漠行星 + 巨型沙中生物 + 稀缺资源"的设定，侵权吗？ | **不侵权**。这些属于"思想/惯用套路"（scènes à faire），著作权不保护 |
| 用《沙丘》的名字、地名、人名、组织名，侵权吗？ | **会**。这些是商标与受保护的角色/元素，一律不用 |
| 照着电影版的美术做造型，侵权吗？ | **有风险**。电影的美术设计是受保护的"表达"，必须差异化 |
| 在宣传里写"沙丘风格"，可以吗？ | **不建议**。可能构成混淆或不正当竞争；只描述自己的作品 |
| 内部文档写"参考电影《沙丘》的摄影语言"，可以吗？ | **可以**，属于描述性使用；但不要把剧照存进仓库或对外分发 |

## 2. 法律框架（够用版）

| 法域 | 保护什么 | 对我们的约束 |
| --- | --- | --- |
| **著作权** | 具体的"表达"：文字、画面、造型、音乐、代码 | 不抄具体造型/镜头/文本；思想、风格、题材不受保护 |
| **商标** | 用来识别商品来源的名称、标志 | 不用 `DUNE`/`沙丘` 及相关专有名词做游戏名、DLC 名、宣传语、商店关键词 |
| **外观设计 / 实用艺术品** | 具体道具、服装、载具的造型 | 不复制扑翼机、蒸馏服、沙虫口器等标志性造型 |
| **反不正当竞争** | 造成混淆、搭便车 | 不暗示"官方授权""正统续作"；不做"像素级致敬" |
| **角色商品化** | 部分法域对知名角色形象的保护 | 不使用任何《沙丘》角色的形象、名称、标志性台词 |

三个常用的抗辩原则，也是我们设计的依据：

- **思想/表达二分**：沙漠、巨兽、资源争夺是"思想"，可以自由使用。
- **场景原则（scènes à faire）**：某一题材必然出现的元素（沙漠、风沙、水源稀缺）不受保护。
- **混同原则**：当某种思想只有一种表达方式时，该表达不受保护（例如"沙"就是沙色）。

## 3. 禁用词表

以下词汇**不得**出现在游戏名、UI、代码标识、资产名、宣传物料、商店关键词中：

### 3.1 作品与品牌

`Dune`、`沙丘`、`Arrakis`、`厄拉科斯`、`Caladan`、`卡拉丹`、`Giedi Prime`、`Dune Messiah`、`Children of Dune`、`Herbert`

### 3.2 势力与角色

`Atreides`、`亚崔迪`、`Harkonnen`、`哈克南`、`Corrino`、`柯瑞诺`、`Fremen`、`弗雷曼`、
`Bene Gesserit`、`贝尼·杰瑟里特`、`Spacing Guild`、`宇航公会`、`CHOAM`、`Landsraad`、
`Sardaukar`、`萨多卡`、`Paul Atreides`、`Leto`、`Jessica`、`Chani`、`Duncan Idaho`、`Gurney Halleck`

### 3.3 造物与概念

`Shai-Hulud`、`沙虫`、`sandworm`、`Melange`、`spice`（作为唯一资源的专名时）、`香料`（同上）、
`Ornithopter`、`扑翼机`、`Stillsuit`、`蒸馏服`、`Holtzman`、`lasgun`、`crysknife`、`晶牙匕`、
`Kwisatz Haderach`、`Litany Against Fear`、`Fear is the mind-killer`

### 3.4 台词与标志

任何电影台词、`DUNE` 标题字体、华纳/传奇影业的标志、电影海报构图。

> 说明：`sandworm`、`spice`、`香料` 在英语/中文里是普通词，但在本题材语境下与《沙丘》强绑定。
> 我们**主动弃用**，改用 `Elder` / `鸣沙兽`、`Vena Salt` / `渊盐`，既避风险，也建立自己的识别度。

## 4. 差异化对照

| 维度 | 《沙丘》 | 《鸣沙》 | 差异强度 |
| --- | --- | --- | --- |
| 星球 | 厄拉科斯，单一沙漠行星，帝国封地 | 阿什卡，旱海行星，**特许开采区** | 中（同为沙漠星球，但政治结构不同） |
| 核心资源 | 香料：生物产物、致幻、开启预知、导航必需 | 渊盐：**矿物**、无致幻、无预知、只用于工业与能源 | **强** |
| 巨兽 | 沙虫：圆口利齿、垂直冲出、吞噬一切、被奉为神 | 鸣沙兽：**三瓣颚、背脊晶簇、螺旋横向潜行、非捕食性翻沙者** | **强** |
| 势力结构 | 皇帝 + 两大贵族家族 + 宇航公会 + 修会 + 原住民 | **特许公司 + 运输行会 + 中立守井者**；无皇权、无贵族、无修会 | **强** |
| 原住民 | 弗雷曼：游牧、战士、宗教预言 | 井民：**定居、守井、中立、不参战** | **强** |
| 主角 | 天选之子、救世主叙事 | **没有主角**；演示里只有"玩家" | **强** |
| 宗教/预言 | 核心戏剧引擎 | **完全不存在** | **强** |
| 建筑 | 金字塔/巨碑、粗野主义混凝土 | **沙漏/倒锥母题**、骨瓷与黄铜 | 中（同为粗野主义，但母题不同） |
| 载具 | 扑翼机（扑翼飞行） | **帆撬（三滑板 + 帆，地面）** | **强** |
| 服装 | 蒸馏服：全身管路、循环系统 | **三层织物 + 陶瓷片**，无管路 | **强** |
| 色彩 | 沙色 + 蓝眼 + 橙香料 | 沙色 + **青白冷火** + 玄武岩黑 | 中（同为暖沙基调，但强调色不同） |
| 命名 | 阿拉伯/波斯语借词 | **汉语描述性复合词 + 意译英文** | **强** |
| 剧情母题 | 复仇、预言、生态改造、帝国政治 | **无剧情**；只有环境事件 | **强** |

**结论**：相似之处集中在"沙漠 + 巨兽 + 资源"这三个**思想层面**的要素；
所有**表达层面**的东西（名字、造型、结构、色彩强调、命名法、剧情）都做了明确区分。

## 5. 视觉边界

| 可以做 | 不可以做 |
| --- | --- |
| 参考"巨物尺度对比""单色场景""硬光深影""大气透视"这些**摄影语言** | 逐帧翻拍电影构图 |
| 用"粗野主义混凝土"这一**建筑风格**（属于公共领域的风格） | 复制电影中的具体建筑造型与比例 |
| 用"层叠织物 + 面罩"这一**服装类型** | 复制蒸馏服的管路、接口、配色与轮廓 |
| 用"沙色 + 黑色"这一**色系** | 直接提取电影画面的 LUT 或色板数值 |
| 自己合成风声、低频、钟声 | 采样电影配乐或音效 |
| 自绘/程序化生成概念图 | 把电影剧照存进仓库或用作 mood board |

## 6. 宣发口径

| 场景 | 可以说 | 不可以说 |
| --- | --- | --- |
| 对外新闻稿 | "一款沙漠行星题材的跨引擎技术演示" | "沙丘风格""Dune-like""致敬《沙丘》" |
| 社交媒体 | 描述自己的世界：双日、冷火、鸣沙兽 | 使用 `#Dune` `#沙丘` 标签蹭流量 |
| 商店页 | 关键词围绕自身设定 | 把 `Dune` 写进关键词/对比栏 |
| 内部文档 | "参考电影《沙丘》的摄影语言"（描述性） | 复制剧照、逐条对照分镜 |

**一句话**：可以承认"灵感来源"，但不要用别人的名字卖自己的东西。

## 7. 内部流程

1. **清洁室（clean room）**：参与设计的人只读文字描述与公开的摄影理论，不临摹电影画面。
2. **创作记录**：保留本文档、设计草图、版本历史 —— 证明独立创作过程（也是本仓库提交历史的作用）。
3. **Mood board 规则**：只允许"文字描述 + 自绘 + 公共领域照片（如地质/沙漠摄影）"，不允许电影截图。
4. **命名审查**：任何新专有名词，先在 §3 禁用词表里过一遍，再查商标库。
5. **资产审查**：引入任何第三方资产，必须记录来源与许可证（现有 `assets/characters/kenney-protagonists/SOURCE.md` 是范例）。

## 9. 风险矩阵

| 风险项 | 可能性 | 影响 | 现状 |
| --- | --- | --- | --- |
| 名称/商标冲突 | 低 | 高 | 已用自造词，待检索 |
| 造型被指抄袭 | 中 | 高 | 已做母题/解剖/服装差异化 |
| 剧情被指改编 | 极低 | 高 | 无剧情 |
| 宣传语混淆 | 中 | 中 | 已定口径 |
| 音乐/音效侵权 | 低 | 中 | 全程序化 |
| 第三方资产许可证 | 低 | 中 | 仅 Kenney CC0，已记录 |

**最大的剩余风险是"造型"**：粗野主义 + 沙色 + 巨构这个组合本身就带着《沙丘》的影子。
应对方式不是躲，而是**把母题做绝**：沙漏形制、三瓣颚、青白冷火、帆撬 ——
让任何一张截图都能被指认出"这是《鸣沙》，不是《沙丘》"。
